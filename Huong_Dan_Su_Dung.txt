2. CÁC LỆNH CHẠY TRÊN TERMINAL (CỰC KỲ ĐƠN GIẢN):
--------------------------------------------------------------------------------

A. Chạy ứng dụng giao diện Menu (CLI):
   > python app.py
   (Bạn có thể bấm các số 1..8 để Thêm, Xem, Sửa, Xóa, Tìm kiếm, Xem Thống kê, Sao lưu backup).

B. Chạy ứng dụng giao diện Web hiện đại (mở trình duyệt xem trực quan):
   > python app.py --web
   (Mở trình duyệt gõ: http://localhost:8000 để quản lý tài liệu trên Web).

C. Chạy kiểm thử tự động (để chụp ảnh minh chứng cho báo cáo):
   > python test_kiem_thu.py
   (Kết quả sẽ hiển thị 5/5 bài kiểm tra đều OK).

D. Chạy phiên bản Dart:
   > dart run app.dart
